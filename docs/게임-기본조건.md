# 게임 기본 조건

> **이 틀로 만드는 게임이 무엇인지에 대한 단일 기준(SSOT)입니다.** 바뀌면 거의 모든 코드가 영향을 받는 조건을 모읍니다.

---

## 1. 무엇을 만드는가

- **옛 PC 게임의 결로 만드는 게임**입니다. 1 ~ 8 비트 화면, 브라운관, 도트 글꼴이 정체입니다.
- **입력이 단순합니다.** 방향 넷과 확인, 취소, 메뉴가 전부입니다. 마우스와 손가락도 같은 명령으로 들어옵니다.
- **한 프로젝트에 게임 한 편입니다.** 이 틀을 복제해 게임 하나를 만듭니다. 타이틀에서 시작을 고르면 바로 들어갑니다. 게임을 얹는 방법은 `docs/게임-모듈-규약.md`.
- 기반 엔진은 `libs/vanilla.js` 입니다. git 서브모듈이라 원본을 그대로 씁니다. 엔진 안에서 텍스처, 노드, 3D 를 쓰는 것은 정체에 영향을 주지 않는 한 상관없습니다.

## 2. 플랫폼

| 항목 | 값 |
|---|---|
| 개발, 테스트 | 웹 빌드 (브라우저) |
| 출시 | **스팀 (윈도우, 스팀덱)**, Electron 으로 묶습니다. `platforms/desktop`, `platforms/steam` |

## 3. 화면

- **가로 전용. 창은 1280 × 800 (16:10, 스팀덱 화면 그대로)입니다.**
- 그 안에 브라운관 모니터 그림이 꽉 차고, 화면 구멍에 게임이 놓입니다. 게임이 그리는 논리 영역과 베젤 두께는 프로젝트가 정합니다. (`src/game/constants.js` 의 기준 해상도, `src/game/crt.js` 의 구멍 자리)
- **백버퍼가 기준 해상도로 고정**되고 창에는 정수 배율로만 키웁니다. 도트가 흐려지지 않습니다. (`src/game/viewscale.js`)
- 그 위에 `src/game/crt.js` 가 모니터 그림과 볼록 렌즈, 주사선, 형광 마스크를 얹습니다. 설정에서 끕니다.
- 화면 모드: 정수 배율(기본), 창 맞춤(설정). 개발 확인용으로 PageUp / PageDown 으로 다른 크기를 돌려 봅니다. (`src/game/devicesize.js`)

## 4. 색

- **모니터 색은 여덟입니다.** 1 비트 녹색, 흰색, 적색, 청색 / 2 비트 녹색, 흰색 / 4 비트 16 색 / 8 비트 256 색.
- F9 가 앞으로, F10 이 뒤로 돌립니다. 설정에도 있습니다.
- 2 비트는 단색 브라운관이 내던 네 단(꺼짐, 약함, 보통, 강함)입니다. 16 색, 256 색은 VGA 기본 팔레트(`src/game/vgapalette.js`)입니다.
- **그리는 쪽은 색의 뜻만 말합니다.** `Colors` 의 열쇠를 주면 `src/game/display.js` 가 지금 색 수에 맞는 값을 돌려줍니다.

## 5. 조작

- **방향 넷 + 확인 + 취소 (+ 메뉴) 가 전부입니다.**
- 키보드: 방향키, WASD = 방향, Enter, Space, Z, J = 확인, Backspace, X, K = 취소, ESC = 메뉴.
- 게임패드(W3C 표준 매핑): 십자키, 왼쪽 스틱 = 방향, A = 확인, B, X = 취소, Start = 메뉴.
- 마우스: 왼쪽이 확인, 오른쪽이 취소. 항목을 눌러 고를 수 있습니다.
- 손가락: 끌면 방향, 톡 치면 확인, 두 손가락은 취소, 길게 누르면 메뉴. 손가락으로만 노는 기기에는 화면 아래에 가상 패드가 섭니다.
- 방향은 누르고 있으면 반복됩니다. 확인, 취소는 누른 순간 한 번입니다.

## 6. 비주얼

- 상태는 색(강조, 목표, 완료, 막힘)과 움직임(미끄러짐, 흔들림, 튀어오름)으로 말합니다. 투명도와 배율은 바꾸지 않습니다. 배율을 바꾸면 도트가 깨집니다.
- 그림을 쓸 때는 **밝기 네 단의 마스크**로 구워 두고 그리는 쪽이 `Colors` 의 열쇠로 물들여 찍습니다. 색 수가 바뀌어도 어긋나지 않습니다. (`tools/bake-sprites.py`, `src/game/sprite.js`)
- 규약은 `docs/UI-규약.md`.

## 7. 글자

- **도트 글꼴**을 설계 크기의 정수 배로만 씁니다. 기본은 갈무리(Galmuri, SIL OFL)입니다.
- 엔진의 글자 안티앨리어싱을 꺼서 구운 글자의 가장자리를 걷어 냅니다. (`src/game/viewscale.js`)
- 여러 말을 지원하려면 글자 표를 숫자 번호로 두고 말마다 글꼴을 바꿔 씁니다. 갈무리에는 한자도 가나도 없어 한국어 밖의 말에는 다른 도트 글꼴이 필요합니다.
