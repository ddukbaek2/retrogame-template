# UI 규약

> **화면 시각, 크기, 움직임 규약의 단일 기준(SSOT)입니다.** 무엇을 어디에 놓고 어떻게 움직이는지를 적습니다.

---

## 1. 기본 방향, 도트 글꼴 한 가지

- **바탕은 종이, 글자는 갈무리.** 판, 선, 상자, 게이지, 그림자, 그라데이션이 없습니다.
- **게임의 종이 색, 먹 색, 강조색은 따로입니다.** 타이틀의 종이는 `background` #0e0e12 이고, 게임에 들어가면 `src/game/identity.js` 의 값대로 `background` `textPrimary` `accent` 가 그 편의 종이, 먹, 강조색으로, `textDim` `textFaint` 는 먹을 종이에 55 %, 25 % 섞은 색으로, `cyan` `green` `red` 는 종이가 밝으면 어두운 계열로 되짚혀 칩니다. 화면 코드는 여전히 `Colors` 의 열쇠만 씁니다.
- **도트 글꼴 모드.** 엔진이 구운 글자의 알파를 0, 255 로 갈라 안티앨리어싱을 걷어 내고 텍스처를 보간 없이 찍습니다. 화면 모드의 기본은 정수 배율입니다.
- **런처 HTML 은 참고 프로젝트와 똑같습니다.** 캔버스 `100vw × 100vh`. 도트 보간 끄기, 캔버스 크기, 자리는 `devicesize.js` 가 코드로 합니다.
- **화면은 세 겹입니다.** 전체 화면(브라우저 창) 안에 **게임 화면 1280 × 800** 이 놓이고, 그 안에 **브라운관 화면 960 × 720**(VGA 640 × 480 의 1.5 배)이 놓입니다. 화면 모드(PageUp, PageDown, 설정)가 재는 것은 늘 가운데의 게임 화면이고, 그 바깥은 검은 띠입니다. 브라운관을 끄면 모니터 테두리가 없어진 만큼만 게임이 커집니다. 비율(4 : 3)은 그대로라 좌우에 검은 띠가 남습니다.
- **안전 영역 48 px.** 볼록 효과는 화면 구멍을 꽉 채우려고 그림을 조금 넓게 떠서 봅니다(오버스캔). 그 대가로 가장자리 한가운데가 48 px 남짓 가려지므로, 글자는 `SAFE_MARGIN` 안쪽에 둡니다. 머리글과 아래 줄의 자리 값(`HEADER_CENTER_Y`, `HEADER_SIDE_MARGIN`, `HINT_CENTER_Y`)이 그 값에서 나옵니다. 설정의 "볼록 확인 격자"로 눈으로 잽니다.
- **F9 는 모니터 색을 다음 것으로 돌립니다.** 설정 창을 거치지 않고 그 자리에서 바뀌고, 끝에 이르면 처음으로 돌아옵니다. (사용자 요청, 2026-09-10)
- **표시 장치**(`src/game/display.js`). 화면 코드가 말한 색을 지금 설정한 색 수로 바꿔 돌려줍니다. 1 비트 녹색(기본), 1 비트 흰색, 2 비트 녹색, 2 비트 흰색(단색 브라운관의 네 단, 꺼짐, 약함, 보통, 강함), 4 비트 16 색, 8 비트 256 색. 16 색과 256 색은 VGA 기본 팔레트(`src/game/vgapalette.js`)에서 가장 가까운 색으로 붙입니다. `palette.js` 가 편마다의 되짚기를 한 뒤 여기를 한 번 거치므로, 브라운관 필터를 끄든 켜든 색 수는 그대로입니다.
- **브라운관 모니터**(`src/game/crt.js`). 창 전체를 덮는 캔버스가 모니터 그림(`assets/monitor/bezel.png`, 640 × 400 도트 × 2, 16 색, 구멍 960 × 720 이 알파 0, 베젤 양옆 160, 위아래 40)을 그리고, 게임 캔버스(960 × 720, 1 : 1)를 매 프레임 텍스처로 받아 화면 구멍에 **볼록 렌즈**로 그립니다: 배럴 0.12(가장자리 한가운데가 구멍에 닿고 모서리는 휘어짐으로 잘림, 잘린 자리는 베젤 안쪽 테와 이어지는 검정), 주사선(1 배에서는 두 줄마다), 형광 글로우(이웃 네 픽셀), 형광 마스크. 비네트, 둥글리기 없음. 화면 코드가 바깥 40px 을 여백으로 두면 모서리 잘림에 걸리지 않습니다. 설정 **모니터 프레임**(모니터 그림)과 **볼록 효과**(렌즈, 주사선, 형광)는 따로 켜고 끕니다. **모니터 색은 여기가 아니라 표시 장치(`src/game/display.js`)가 맡습니다**, 브라운관을 꺼도 색 수는 그대로입니다. 오른쪽 아래 입력 장치 아이콘도 이 덮개가 모니터 프레임 자리에 얹습니다.
- 도트가 고르게 보이는 규칙: 백버퍼 **960 × 720** 고정(`viewscale.js`, 창 1280 × 800 안의 모니터 화면 구멍), 글자 크기는 글꼴 em 격자의 정수 배(`UiFontSize`, 갈무리9 는 10 칸이라 20, 30, 40, 60, 90), 그리는 자리는 정수 픽셀(`text.js`), 배율 트윈 없음. 화면 코드는 `REFERENCE_RESOLUTION_WIDTH`, `HEIGHT` 를 쓰고 1280, 800 을 직접 적지 않습니다.
- 색은 `Colors` 뿐입니다. 뜻이 다른 색은 값도 다릅니다.

| 색 | 뜻 |
|---|---|
| `textPrimary` | 보통 글자, 움직이는 글자 |
| `textDim` | 머리글, 안내, 핀(고정 글자), 못 쓰는 항목, 살아 있지 않은 축의 표식 |
| `textFaint` | 빈칸 `·`, 목표 자리의 옅은 글자, 지워진 글자 |
| `accent` (노랑) | 커서, 고른 항목, 날개, 살아 있는 축의 표식 |
| `cyan` | 목표 글, 목록의 값 |
| `green` | 완료, 제자리에 온 글자, 깬 판 번호 |
| `red` | (예비) 막힘 |
| `magenta` `orange` `lime` | 끼우기의 조각 색 (`PIECE_COLOR_KEYS` 순서: cyan → magenta → orange → lime → green) |

## 2. 부품

| 자리 | 부품 |
|---|---|
| `src/game/text.js` | `drawText` `drawGlyphInCell` `drawLines` `measureTextWidth` `readLineHeight` |
| `src/ui/` | `ScreenNode`(화면 바탕, 머리글, 안내 줄, 들어오는 움직임) `ListNode`(세로 목록) `LetterField`(글자 무리) `layout.js` `uitime.js` |
| `src/view/` | `PuzzleView`(판 자리 잡기, 되돌리기, 빈칸, 목표 줄) → `FoldView` `PushView` `TiltView` `LoopView` `ReplaceView` `FitView` `StrikeView` `ReverseView` `LightView` `JumpView` `SpaceView` `TraceView` `FillView` `ComposeView` |
| `src/screen/` | `TitleScreen` `ChapterScreen` `LevelScreen` `PlayScreen` |
| `src/panel/` | `MenuWindow`(멈춤) `SettingsWindow`(설정) `HelpWindow`(규칙), 겹창이 아니라 화면입니다 |

- 목록(`ListNode`): 고른 항목은 강조색이 되고 오른쪽으로 16px 밀립니다(`approachValue` 22). 왼쪽의 `>` 는 깜빡이는 글자 커서(0.9 초 주기, 62% 켜짐). 값이 있는 항목은 오른쪽 끝에 값(고르면 cyan).
  열을 둘 이상 두면(`setColumnCount`) 항목이 열마다 위에서 아래로 차고, 상하는 열 안에서 순환하며 좌우는 열을 옮깁니다. 장 선택이 2 열입니다.
- 글자 무리(`LetterField`): 번호로 구별되는 글자들이 새 자리로 미끄러집니다(`approachValue` 18). 막히면 0.28 초 흔들림(6px), 완료되면 위에서부터 차례로(0.05 초 간격) 0.9 초 튀어 오름(14px).

## 3. 글자 크기 (`UiFontSize`)

| 티어 | 글꼴, 크기 | 용도 |
|---|---|---|
| tiny | 갈무리9 × 2 = 18 | 안내 줄, "목표" 이름표, 조각 표식 |
| small | 갈무리11 × 2 = 22 | 머리글, 목록 값, 설명, 접는 선 표식, 돌리기의 목표 판 |
| medium | 갈무리11 × 3 = 33 | 목록 항목, 목표 글, 큰 판(8 칸 이상)의 글자 |
| large | 갈무리11 × 4 = 44 | 판의 글자(7 × 5 이하), 판 번호 |
| huge | 갈무리14 × 4 = 56 | "완료", "멈춤", "설정" |
| title | 갈무리14 × 6 = 84 | 타이틀 제목 |

- 판의 칸: 7 × 5 이하면 64px(large), 넘으면 48px(medium). (`PuzzleView.layoutGrid`)
- 줄 높이는 글자 크기의 1.5 배. 목록은 거기에 6px 을 더합니다.

## 4. 움직임

- **알파, 배율 트윈 없음.** 옮기기와 색뿐입니다.
- 화면 진입: 글자들이 오른쪽 40px 에서 0.35 초 `easeOutCubic` 으로 들어옵니다. (`ScreenNode.readEnterOffset`)
- 타이틀 제목: 3.2 초 주기로 위아래 4px 숨쉬기.
- 판 번호: 고르면 8px 떠오름.
- 완료: "완료" 가 60px 위에서 0.5 초 `easeOutBack` 으로 떨어져 내려오고, 글자들이 차례로 튀어 오릅니다.
- 소리(`beep.js`): 이동, 확인, 취소, 막힘, 판이 바뀜(스윕), 완료(아르페지오). 전부 합성 사각파, 삼각파입니다.

## 5. 배치

### 공통
- 머리글: y 44, 좌우 여백 40, small, textDim. 왼쪽은 장 이름, 판 번호(또는 제목), 오른쪽은 수, 최소 수(또는 완료 수).
- 안내 줄: y 756(`HINT_CENTER_Y`), tiny, textDim, 가운데. 조작만 적습니다.
- 입력 장치 아이콘: 오른쪽 아래(x 1208 ~ 1240, 안내 줄과 세로 가운데를 맞춤), 16 × 10 도트를 2 배로 찍은 단색 비트맵(textDim). 지금 쓰는 장치(키보드 + 마우스, 게임패드, 터치)를 마지막 입력으로 판단해 어느 화면에서나 씬이 맨 위에 그립니다(`src/game/inputsource.js`, `src/ui/inputicon.js`). 이 게임에서 글자가 아닌 유일한 그림입니다.
- **가상 게임패드**: 손가락으로만 노는 기기(`pointer: coarse` 이고 `hover: none`)에서는 모니터 아래에 패드가 섭니다.
  게임 화면과 아주 별개인 것이라 브라운관 필터 밖에 따로 캔버스를 둡니다. (`src/game/virtualpad.js`)
  왼쪽에 십자키, 오른쪽에 **A(왼쪽, 확인)** 와 **B(오른쪽, 취소)**, 가운데 아래에 SELECT 와 START 가 있습니다.
  SELECT 와 START 는 자리만 있고 아직 하는 일이 없습니다. (사용자 지시, 2026-09-13)
  패드가 서면 그 높이만큼 덜어 낸 자리에 모니터를 놓습니다. (`src/game/devicesize.js`)
- 판: 가운데 (640, 372)(`PLAY_CENTER`). 목표 줄은 판 아래 58px 에 "목표"(tiny) + 목표 글(medium, cyan).
- 완료 글자: y 710, huge, green. 그때 안내 줄은 "확인 다음 판, 취소 판 목록".

### 타이틀
- 제목 (640, 300) title. 목록(시작, 설정) y 470 가운데 정렬 medium.

### 장 선택
- 2 열 목록 x 200, y 140, 폭 900(열 450), medium, 7 줄. 값은 "완료 수 / 판 수". 머리글 오른쪽에 전체 "완료 n / N". 고른 장의 한 줄 설명 y 640 small, textDim.

### 판 선택
- 6 열 격자(30 판 = 5 줄), 칸 132 × 92, 세로 가운데 360. 번호 large. 깬 판 green, **최소 수로 깬 판 cyan**, 고른 판 accent + 8px 떠오름 + 왼쪽 `>`. 아래 y 640 에 "최소 n 수, 기록 n 수, 최소로 깼습니다".

### 멈춤, 설정, 규칙
- 제목 huge (y 250, 220, 200), 목록 medium (y 350, 330). 규칙 창은 장 이름 아래 규칙 세 줄(small, 줄 간격 41)과 조작 한 줄(cyan). 아래 화면은 감춥니다(글자가 겹치지 않게).

### 장별 판
- 접기: 판 밖 20px 에 접는 선 표식(`v` 위, `^` 아래, `>` 왼, `<` 오른쪽). 날개 글자 accent.
- 밀기, 기울이기: 목표 자리 옅은 글자, 핀 textDim, 커서 `_` accent(밀기).
- 돌리기: 판을 왼쪽으로 당기고 오른쪽에 목표 판(small, cyan).
- 바꾸기: 글 한 줄(large) → 목표 → 규칙 목록("가나 → 다", 고른 것 accent).
- 끼우기: 조각마다 색, 고른 조각만 제 색.
- 지우기: 줄, 칸 커서 표식, 지워진 글자 textFaint.
- 뒤집기, 띄어쓰기, 글자 짓기: 글 한 줄(large) 아래 `^` 커서(자리, 틈). 뒤집기의 시작 표시는 cyan `^`, 글자 짓기의 모음은 cyan.
- 켜기: 켜진 글자 textPrimary, 꺼진 글자 textFaint, 커서 칸 accent + `v` `>` 표식.
- 뛰어넘기: 커서 칸 글자 accent, 자유 때 흐린 `v` `>`, 잡으면 네 방향 강조.
- 한붓 읽기: 밟은 글자 green, 지금 칸 accent, 다음 글자 후보 cyan.
- 채우기: 없는 자리는 아무것도 없음, 빈칸 `·`, 고르는 중인 후보 글자 accent, 아래에 낱말 목록(cyan)과 남은 글자(textDim).
