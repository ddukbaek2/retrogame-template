# 엔진 보완 내역

> **`libs/vanilla.js` 에 이 틀이 요구한 수정을 전부 여기에 적습니다.**

엔진은 **git 서브모듈**입니다. 원본 리포는 https://github.com/ddukbaek2/vanilla.js 입니다.
그래서 고친 것은 사본에 남지 않고 **원본에 들어가 있습니다.** 서브모듈을 올리면 따라옵니다.

## 고칠 일이 생겼을 때

1. **특정 게임을 위한 이름이나 동작을 엔진에 박지 않습니다.** 엔진이 여는 것은 일반적인 옵션이어야 합니다.
   예를 들어 "도트 글꼴 모드" 가 아니라 "글자 안티앨리어싱 끄기" 입니다. 하는 일 그대로 이름 짓습니다.
2. **기본값은 지금 동작 그대로 둡니다.** 다른 프로젝트가 서브모듈을 올렸을 때 화면이 달라지면 안 됩니다.
3. 원본 리포(`dev` 브랜치)에 커밋하고 올린 뒤, 이 저장소의 서브모듈을 그 커밋으로 옮깁니다.
4. 여기에 적습니다.

## 들어간 것

- **`src/core/graphic/textstringtexturecache.js`, 글자 안티앨리어싱 옵션.** (2026-09-14)
  `setTextAntialiasEnabled(boolean)` 을 내보냅니다. 끄면 (1) 구운 글자의 알파를 128 문턱으로 0, 255 로 갈라 캔버스 `fillText` 의 안티앨리어싱 가장자리를 걷어 내고, (2) 텍스처 필터를 `LINEAR` 대신 `NEAREST` 로 둡니다.
  이 틀은 `src/game/viewscale.js` 의 `applyPixelFixedScale` 에서 끕니다. 기본은 켜짐이라 기존 동작은 그대로입니다.
  켜고 끄는 시점 이후에 굽는 글자부터 적용됩니다. 캐시된 글자는 그대로입니다.
- **`src/core/engine.js`, `EngineConfiguration.preserveDrawingBuffer`.** (2026-09-14)
  켜면 프레임이 끝난 뒤에도 그린 것이 캔버스에 남습니다. 캔버스 위에 얹은 브라운관 필터(`src/game/crt.js`)가 매 프레임 `texImage2D` 로 읽으려면 필요합니다. 기본은 꺼짐입니다. 한 번 더 복사하는 만큼 비용이 있습니다.
  이 틀은 `src/main.js` 에서 켭니다.

## 알아 둘 것 (엔진을 고치지 않고 게임 쪽에서 감싼 것)

- **글자 텍스처는 기본이 `LINEAR` 필터입니다.** (위의 옵션을 끄면 `NEAREST`) 반 픽셀 자리에 그리면 번집니다. `src/game/text.js` 가 자리를 정수로 맞추고 베이스라인을 `alphabetic` 으로 두어 피합니다. `middle` 베이스라인은 `(ascent - descent) / 2` 가 반 픽셀이 될 수 있습니다.
- **글자 굽기 배율은 변환 행렬의 배율을 0.25 단위로 양자화한 값입니다.** (`graphic.calculateTextBakeScale`) 백버퍼를 기준 해상도로 고정하면 배율이 정확히 1 이라 도트 글꼴이 설계 크기 그대로 구워집니다. `graphic.scale()` 로 글자를 키우면 배율이 바뀌어 다시 구워지고 도트가 깨집니다. 쓰지 않습니다.
- **`ViewManager.setMaxRenderPixelRatio` 는 렌더 배율의 상한입니다.** 백버퍼는 캔버스의 CSS 크기에 `min(devicePixelRatio, 상한)` 을 곱한 값입니다. 기준 해상도로 고정하려면 상한을 `기준 가로 / 캔버스 가로` 로 둡니다. 창이 기준보다 작으면 상한이 1 을 넘는데, 그때는 제한이 걸리지 않아 줄여 그립니다. (`src/game/viewscale.js`)
- `InputManager` 는 키를 `keydown` 의 `code` 로 `pushKey` 합니다. 이 틀은 그 상태를 쓰지 않고 `src/game/command.js` 가 `keydown` / `keyup` 을 따로 받아 "누른 순간" 과 반복을 만듭니다.
- `GamepadManager` 는 단추, 축 변화를 `console.log` 로 찍습니다. 패드가 꽂혀 있으면 로그가 납니다. 오류가 아닙니다. 이 틀은 `isButtonPressed`, `getAxisValue` 를 프레임마다 읽습니다.
