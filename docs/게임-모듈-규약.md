# 게임 모듈 규약

> **게임 한 편을 이 틀에 더하는 방법의 단일 기준(SSOT)입니다.**
> 한 앱에 편을 여럿 담을 수 있고 허브에서 고릅니다. 한 편만 담고 허브를 건너뛰어도 됩니다.
> 가장 작은 예가 `src/games/sample/` 에 있습니다. 그것을 베껴 시작하면 됩니다.

---

## 1. 틀

```
src/main.js                      씬: 타이틀, 허브(게임 목록), 설정 + 게임 모듈 관리 + 명령 배분
src/game/gamemodule.js           GameModule 바탕 (화면 만들기, 길 찾기, 진행 저장)
src/game/games.js                게임 목록 (여기에 생성자를 더하면 허브에 나타납니다)
src/games/<id>/                  게임 한 편
   <id>game.js                   모듈 (GameModule 파생)
   logic/*.js                    순수 규칙, 생성 (엔진, 브라우저 API 금지, Node 에서도 돕니다)
   screen/*.js                   화면들 (ScreenNode 파생)
   data/*.json 또는 logic 안의 표   내용 (아이템, 적, 사건, 낱말 …), 자료가 크면 assets/data/<id>/ 에 두고 fetch
docs/games/<id>.md               그 게임의 기획, 규칙, 볼륨, 조작, 저장
```

- 화면 이름은 씬이 `"<id>:<이름>"` 으로 등록합니다. 모듈의 `changeScreen("이름")` 이 그리로 갑니다.
- 화면은 `ScreenNode` 를 상속하고 **생성자에 모듈을 받습니다**(`super(module, "<id>:이름")`). 화면 안에서 `this.getScene()` 이 곧 모듈입니다. 길 찾기(다음 화면, 나가기, 설정)는 **모듈의 메서드**로 합니다. 씬을 직접 부르지 않습니다.
- 들어오면 `getEntryKey()` 화면이 열립니다. 게임 안의 메뉴에 **"게임 목록으로"** 를 두고 `module.exit()` 을 부릅니다. 설정은 `module.openSettings()`.
- 진행은 `module.readData(기본값)` / `module.writeData(자료)` 로 게임 이름 아래 저장합니다(localStorage). 설정의 "진행 지우기" 는 전 게임을 지우고 `onProgressErased()` 를 부릅니다, 들고 있는 자료를 기본값으로 되돌립니다.
- 자료 파일이 필요하면 `async load()` 에서 `loadDataTable(경로)` 로 받습니다. (`src/game/datatable.js`)

## 2. 반드시 지킬 것 (모든 게임 공통)

- **화면에는 글자와 바탕색뿐입니다.** 그림, 도형(사각형, 선, 원, 게이지, 막대), 아스키 아트 전부 금지. 체력은 `체력 34 / 50` 처럼 숫자로, 진행은 `3 / 10` 처럼 글자로. 표는 글자를 열 맞춰 놓는 것으로 그립니다. (`docs/UI-규약.md`)
- **입력은 방향 넷 + 확인 + 취소 (+ 메뉴)뿐입니다.** 글자 입력 없음. 고르는 것은 전부 목록(`ListNode`)이나 커서로. 취소는 "뒤로, 되돌리기", ESC 는 메뉴.
- **글자는 갈무리 도트, 티어(`UiFontSize`)만.** 배율, 알파 트윈 없음. 움직임은 옮기기와 색.
- **글자끼리 겹치지 않습니다.** 한 화면에 너무 많으면 화면을 나눕니다. 긴 목록은 `ListNode` 를 여러 열로 두거나 쪽을 나눕니다(쪽 넘김은 좌우).
- **이야기, 캐릭터, 세계관을 쓰지 않습니다.** 사건, 아이템, 적은 이름과 수치와 효과뿐입니다. 문장은 "무엇이 어떻게 됐다" 를 한 줄로.
- **존댓말.** 화면 문구, 주석, 문서 전부. (CLAUDE.md)
- **볼륨.** 한 편이 한두 시간은 붙잡는 게임이어야 합니다. 진행(잠금 해제, 기록, 단계, 이어하기)이 있어야 하고, 내용(적, 아이템, 사건, 낱말, 판)은 수십에서 수백 개를 표로 둡니다. 절차 생성이면 씨앗 난수(`createRandom`)로.
- **규칙은 로직에, 연출은 화면에.** `logic/` 은 엔진, 브라우저 API 를 들여오지 않고 Node 에서 돌아, 도구나 검증이 씁니다.
- **다른 편과 종류가 겹치지 않습니다.** (사용자 지시, "컨셉 안 겹치게") 다른 편의 파일을 건드리지 않습니다.
- 공용 파일(`src/game/*` `src/ui/*` `src/main.js` `src/screen/*` `src/panel/settingswindow.js`)은 손대지 않습니다. 필요한 부품은 제 게임 폴더 안에 만듭니다.

## 3. 공용 부품

| 부품 | 쓰임 |
|---|---|
| `ScreenNode` (`src/ui/screennode.js`) | 화면 바탕. `onEnter` `handleCommand(command)` `drawHeader(graphic, 왼쪽, 오른쪽)` `drawHint(graphic, 안내)` `readEnterOffset()` |
| `ListNode` (`src/ui/listnode.js`) | 세로 목록(여러 열 가능). 항목 `{ id, label, valueText?, isEnabled? }`, `setSelectHandler` `setChangeHandler`(좌우) `handleCommand` → "move" \| "confirm" \| "change" \| "blocked" \| "none" |
| `LetterField` (`src/ui/letterfield.js`) | 글자들이 미끄러지고 흔들리고 튀는 무리 (판 위 글자에) |
| `drawText` `drawLines` `measureTextWidth` `readLineHeight` (`src/game/text.js`) | 글자 그리기 (정수 자리, 세로 가운데) |
| `Command` (`src/game/command.js`) | up, down, left, right, confirm, cancel, menu |
| `beepMove` `beepConfirm` `beepCancel` `beepBlocked` `beepAction` `beepClear` (`src/game/beep.js`) | 효과음 |
| `approachValue` (`motion.js`), `easeOut*` (`easing.js`) | 움직임 |
| `createRandom` `randomInteger` `pickOne` `shuffle` `chance` (`src/games/puzzle/logic/random.js`) | 씨앗 난수, 제 게임 폴더로 복사해 씁니다(다른 편 파일을 들여오지 않습니다) |
| `Colors` `UiFontSize` `HINT_CENTER_Y` `HEADER_*` (`src/game/constants.js`) | 색, 글자 티어, 자리 |

- **종이, 먹, 강조색은 편마다 제 것입니다.** `src/game/identity.js` 의 표에 `<id>: { paper, ink, accent }` 한 줄을 더하면 앱이 그 편에 들어갈 때 `Colors` 를 되짚어 칩니다. 화면 코드는 그대로 `Colors` 열쇠만 씁니다. (필요하면 `info` `ok` `bad` 도 정합니다)
- **실시간 게임은 누르고 있는 상태를 읽습니다.** 화면의 `tick(timeDelta)` 에서 `this.getModule().isCommandHeld(Command.left)` 처럼 읽습니다(키보드, 게임패드 공통, 방향, 확인, 취소). `handleCommand` 로 오는 방향 명령은 순간 동작에만 씁니다.

## 4. 검증

- 검증 스크립트는 저장소에 넣지 않고 작업용 임시 폴더에 둡니다. 헤드리스 크롬으로 돌립니다. `launch({ port, page, shotsDirectory })` → `enterGame(page, "<id>")` → 키 입력(`press`), 화면 이름(`readScreenKey`), 모듈 값(`readModuleValue`), 스크린샷(`shot`) → `finish(session)`.
- 게임마다 `qa/run-<id>.cjs` 를 씁니다: 들어가기 → 새로 시작 → 핵심 흐름 30 ~ 100 수(규칙에 맞는 입력을 스크립트가 고름) → 저장, 이어하기, 메뉴, 게임 목록으로 → `errors: 0`. 스크린샷을 눈으로 봅니다(겹침, 잘림).
- 로직은 Node 로 단위 확인합니다(`node --input-type=module -e "import …"` 또는 게임 폴더 안 `logic/package.json` 에 `{ "type": "module" }`).
